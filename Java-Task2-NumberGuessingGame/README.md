# Number Guessing Game

## Description
This is a Java console-based Number Guessing Game developed as part of the OIBSIP Java Development Internship.

## Features
- Random number generation
- Easy, Medium, and Hard difficulty levels
- Limited attempts
- Too High / Too Low hints
- Multiple rounds
- Game summary

## Technologies Used
- Java

## How to Run

```bash
javac NumberGuessingGame.java
java NumberGuessingGame
```

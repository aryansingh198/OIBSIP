# Task 3 • ATM Interface

**Track:** Java Development (OIBSIP)  
**Author:** Aryan Singh

## Objective

A Java console-based ATM Interface application that allows users to perform basic banking operations such as checking balance, depositing money, withdrawing money, and viewing transaction history.

## Tech Stack

- Java (Console Application)

## Features

- User Login
- Check Balance
- Deposit Money
- Withdraw Money
- Transaction History
- Menu-driven Interface

## Files

- Main.java
- ATM.java
- Account.java
- Bank.java
- Transaction.java

## How to Run

```bash
javac *.java
java Main
```
